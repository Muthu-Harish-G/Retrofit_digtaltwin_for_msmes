# Retrofit_digtaltwin_for_msmes
📌 Project Overview

This project aims to transform conventional manufacturing machines into smart, connected machines using a low-cost IoT retrofit system.

The system uses ESP32 microcontrollers and sensors to monitor machine performance, collect operational data, control machine components, and provide a real-time web dashboard.

The primary objective is to help small and medium-sized manufacturing enterprises (MSMEs) move towards Industry 4.0 without replacing their existing machinery.

🎯 Objectives

Retrofit conventional machines with affordable IoT hardware.

Monitor machine operating conditions in real time.

Measure RPM, production cycles, voltage, current, power and energy.

Monitor sound levels for identifying abnormal operating conditions.

Track machine operating time, idle time and job time.

Enable remote machine control through a web dashboard.

Develop reference-based lookup tables for machine performance analysis.

Generate maintenance suggestions based on sensor readings and reference values.
